# flutter-to-web

版本 2.4.0。面向 Vue3/React 开发者，从当前 Tuqiang 源码解释功能、状态、路由与 UI；只讲解，不修改代码。

入口见 [SKILL.md](SKILL.md)：简单问题用最短证据链，完整链路按需展开；用户指定 Vue3 或 React 时只输出对应框架，未指定时给简短心智模型。对照表见 [Web 对照](references/web-analogies.md)；项目事实直接复用 [项目地图](../tuqiang-project-map/SKILL.md) 与 [tuqiang-dev](../tuqiang-dev/SKILL.md) 的 references，需四个技能同根安装。

版本变化见 [根 CHANGELOG](../../CHANGELOG.md)。许可证：Apache 2.0。
