# 国际化规范（双产品）

两个产品都复用 `core_i18n` 的翻译 primitive，但各自维护 manifest、字典、加载与产品文案。不得把途强的九语言覆盖范围默认套给老鹰。

## 1. 代码与 key

```dart
Text('选择品种'.tr);
'绑定{key}成功'.keyTr('旺财');
'共{count}只{type}'.multiKeyTr({'count': '3', 'type': '猫'});
```

`keyTr` 只替换 `{key}`，自定义命名占位符使用 `multiKeyTr`。代码写死的用户可见标题、按钮、Toast、弹窗和权限说明需翻译；日志、fixture、非用户数据及已由后端本地化的文案不机械套 `.tr`。

不要在 Widget/State 的 `final`/`static final` 中缓存翻译结果，语言切换后应重新求值。文案、语言范围或 fallback 不明确时先询问，不自行翻译或扩语种。

## 2. 途强智能

`apps/tuqiang_app/assets/i18n` 当前有九套资源：`zh_CN`、`en_US`、`ar`、`de`、`es`、`fr`、`id`、`it`、`vi`，fallback 为 `en_US`。新增中文 key 时同步九个 JSON；区分 manifest key（如 `zh_CN`）、`Locale` 名（如 `zh`）和协议/持久化代码（如 `zh-CN`）。阿拉伯语需检查 RTL。

`core_i18n`/`TQI18nManager` 负责语言和字典；Feature 或拆分后的 `shared_*` 清理自身语言派生缓存；`apps/tuqiang_app` 的 `LanguageChangeCoordinator` 只聚合执行顺序，不承载具体业务缓存。

## 3. 老鹰在线

`apps/laoying_app/assets/i18n` 当前只声明 `zh_CN` 与 `en_US`，fallback 为 `en_US`。加载由老鹰自己的 `LYI18nLoader`/`LYI18nInitializer` 接入翻译 manager；新增文案只同步产品当前 manifest 所列语言，新增语种必须先有产品决定。

老鹰业务缓存由对应 app-local owner 清理，应用级语言/session 协调沿 `LYAppProvider`、Controller 与现有偏好链处理。不要把途强 `LanguageChangeCoordinator`、Feature cache reset 或九语言假设复制进来。

## 4. 验证

- 校验目标产品 manifest、JSON 语法、key 集合、非空值和 fallback；
- 验证目标产品当前语言、fallback、参数替换及切换后的动态求值；
- 素材也随语言切换时逐一验证 asset 选择；缺目标 PNG 按 [assets-guide.md](assets-guide.md) 先索要；
- 途强跑相关 i18n tests、`standard`/`ohos` 与 `-ProductScope tuqiang`；
- 老鹰跑 loader/initializer/manifest tests、`apps/laoying_app` 与 `-ProductScope laoying`；
- 公共 i18n 变化检查四 target 和 `-ProductScope all`。
