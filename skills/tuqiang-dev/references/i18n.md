# Tuqiang 国际化与展示取值

标题、按钮、Toast、Dialog、空态、错误、权限用途、tooltip、semanticLabel 和图片语言变体触发本流程；日志、协议值、用户输入和后端已本地化内容不机械翻译。

## 先确认值的契约

| 输入 | 正确处理 |
| --- | --- |
| 本地 source key | 在展示边界调用一次 `.tr` / `keyTr` / `multiKeyTr` |
| 已翻译的展示 getter / label | 直接展示，不再 `.tr`、反查 key 或按译文判断业务状态 |
| 后端业务数据、用户输入 | 按字段契约展示，不把名称、地址、接口消息等动态内容当 key |
| code / enum | 复用已有映射；业务判断使用 code / enum，展示使用其 UI getter |

先读已有 getter/组件的实现与调用处。例如 `BeaconTypeUi.displayName`、`TQClientTypeUi.displayName` 已翻译，调用方直接使用。需要兼容旧字段、空值或格式时，在现有 Model/adapter/展示 owner 中按已确认的协议处理一次；下游消费同一结果，禁止各层重复 `??`、空串判断、旧字段试探与兜底。没有协议证据就不增加兼容分支。禁止的是重复解释同一字段契约；不同层真实存在的缺失状态（如 Model 本身为空）仍可处理，不能机械删除必要的 null 检查。

## fallback 只归国际化基础层

- 资源清单以 `apps/tuqiang_app/assets/i18n/manifest.json` 为准；全部 locale 覆盖不能用 `TQI18nManager.supportLangList` 推导，后者只是可选语言列表。
- `packages/core/core_i18n/lib/src/tq_i18n_manager.dart` 的 `getText` 已执行“当前 locale → manifest fallback → 原始 key”。仅缺键（null）回退，空字符串不会回退。
- 因此不新增页面级 `safeTr` / `trOrDefault`、中英判断、第二套查表或 `translated == key` 兜底。译文等于 key 也可能正确；缺译应修复资源，不能以 `.tr` 有返回值作为覆盖证明。
- 业务空态/缺值占位与翻译缺失是不同契约：先在所属 owner 按数据规则取值，确需产品占位时使用已存在或补齐的 source key，再翻译一次。

## 文案修改

1. 按语义复用已有 key；新增 key 或修改占位符时同步 manifest 当前全部 locale，值必须是非空字符串。
2. 只允许 `{identifier}` 占位符且各语言集合一致；`keyTr` 只替换 `{key}`，具名参数用 `multiKeyTr`，参数值为 `String`，不要靠拼接完整句子迁就语序。
3. 普通产品译文注明来源或待语言复核；法律、隐私、付费、安全及多义文案需要正式译文。本次范围可达 Arabic 等 RTL locale 时检查方向性图标、数字/单位与溢出；图片文案使用真实语言 asset。

```dart
Text('选择品种'.tr);
'绑定{key}成功'.keyTr(name);
'共{count}只{type}'.multiKeyTr({'count': count.toString(), 'type': type});
```

不要在顶层、static/final、singleton、Repository/Model cache 等长生命周期 owner 保存译文；在 getter、build 或实际展示时读取。`.tr` 依赖全局当前语言，本身不是纯函数；新写的格式化/取值函数应接收明确的值及需要的 locale/展示文案，不在内部偷偷读取语言或其他全局状态。纯数据函数返回 code/key，已有展示入口负责翻译即可。

## 加载与切换的真实链路

`AppI18nRepository.installStartupTranslations` 启动加载当前语言、中英与 manifest fallback，其他语言由 `ensureLanguageLoaded` 按需合并。区分 translation locale（`zh_CN`）、Flutter Locale（`zh`）及持久化/协议代码（`zh-CN`），复用 `TQLanguageType` 的转换，不手写替换。

改动加载、持久化或缓存时同时检查 Auth 的 `src/page/lang_change_page.dart` 与 Mine 的 `setting/setting_page.dart`：

```text
prepareLanguage → AppI18nRepository.ensureLanguageLoaded
→ setLanguage → clearLanguageCache → Phoenix.rebirth
```

保留加载成功、mounted 检查后再切换的顺序；`LanguageChangeCoordinator` 清理语言相关状态，各缓存仍归原 owner。

## 验证

对本次复用或新增的每个 source key 显式传入 `--key`；脚本也自动发现变更 locale key 和变更 Dart literal 调用：

```text
python -X utf8 <TUQIANG_DEV_SKILL>/scripts/validate_tuqiang_i18n.py --root <TUQIANG_ROOT> --key '<source key>'
```

脚本检查 JSON、重复/空 key、非字符串/空值、全 locale 覆盖、占位符与调用参数，删除后仍有 literal 调用会失败；变量 Map、spread、computed key、collection-if/for 无法静态证明时会 fail-closed。

另沿本次展示链检查“原始值 → 唯一取值 owner → 展示”，确认没有重复兼容或翻译；涉及切语言则验证切换后的现有页面和相关缓存。脚本不证明翻译语义、动态 key、可见硬编码、RTL 或布局，按风险补充 [testing.md](testing.md) 中的验证。
