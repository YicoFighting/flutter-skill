# 国际化规范（tr）

项目不用 intl arb，也不用 getx，而是自研 **core_i18n**：**翻译 key 直接写中文原文**，运行时查 9 个语言的 JSON 映射表。

## 1. 三种写法

```dart
import 'package:core_i18n/core_i18n.dart';

// ① 最常用：中文原文即 key
Text('选择品种'.tr)

// ② 单占位符 {key}
'绑定{name}成功'.keyTr('旺财')          // → "绑定旺财成功"

// ③ 多占位符
'共{count}只{type}'.multiKeyTr({'count': '3', 'type': '猫'})
```

规则：

- UI 上出现的一切用户可见文案（含弹窗按钮、toast、AppBar 标题、权限说明）**必须**包 `.tr`；
- key 用简洁的中文短句；同一句话多处出现就复用同一个 key（JSON 里天然去重）;
- 占位符固定写法 `{name}`，替换时不要拼字符串（否则语序在英语等语言里无法调整）。

## 2. 新增文案的完整步骤【9 个文件一个都不能少】

文案资产在 `apps/tuqiang_app/assets/i18n/`：

```text
manifest.json   zh_CN.json  en_US.json  ar.json  de.json
es.json         fr.json     id.json     it.json  vi.json
```

步骤：

1. 在 `zh_CN.json` 加 `"新文案": "新文案",`（key 与值相同）。
2. 同步在其余 **8 个** JSON 里加同 key 的对应译文。漏了哪个语言，该语言用户就会看到英文兜底或 key 原文。
3. JSON 格式要求：非空字符串键 + 字符串值；loader 会严格校验，写错直接启动抛 FormatException。
4. 不需要改任何 Dart 注册代码——`AppI18nLoader.loadFromAssets` 按 manifest 动态加载。

支持的语言与 locale 名（必须用这些名字）：`zh_CN, en_US, ar, de, es, fr, id, it, vi`；fallback 固定 `en_US`。

## 3. 语言切换机制（了解即可，别自己实现）

- 当前语言存 SharedPreferences（key: `lang_key`），由 `TQI18nManager.initLanguage/setLanguage` 管理；
- 切换后需要清缓存并重建应用，统一走 `LanguageChangeCoordinator.clearCache`（app 层已接好），feature 不要私自处理；
- 判断当前是否中文：`TQI18nManager.isChineseLang`（个别 UI 按语言微调时才允许用）。

## 4. feature 包内使用

feature 包只要 pubspec 里依赖了 `core_i18n`（现有所有 feature 都有），import 后即可用 `.tr`，无需注册任何东西。

## 5. 验证方式

- 改完 JSON 跑一次 `dart run tool/project.dart pub-get standard --enforce-lockfile` 后重新运行 App；
- 自检清单：切到 zh_CN / en_US / ar（阿拉伯语是 RTL 布局，顺带看一眼排版有没有被拉爆）三个语言各看一遍新页面；
- JSON 写坏会在启动时立刻抛异常，报 `Unsupported i18n manifest schema.` 或 `must only contain non-empty string keys` 时优先检查刚改的文件逗号引号。
